# Epignosis (TalentLMS, eFront, TalentCards)

> Epignosis is a learning-technology company serving 70,000+ organizations with cloud training products: TalentLMS (all-in-one LMS), eFront (enterprise LMS), TalentCards (mobile microlearning), and TalentHR. Each product exposes a JSON REST API authenticated with an API key over HTTP Basic auth. Generated by the API Evangelist enrichment pipeline from public sources.

## APIs
- [TalentLMS API](https://www.talentlms.com/features/api-connectors): JSON REST API at https://{domain}.talentlms.com/api/v1/ — users, courses, categories, groups, branches, units, tests, surveys, ILT sessions, timeline. API-key HTTP Basic auth.
- [eFront API](https://app.swaggerhub.com/apis/Epignosis/Efront-API/1.0.0): OpenAPI 3.0.0, 58 operations, base https://ssc.efrontlearning.com/API/v1.0 — users, courses, branches, groups, categories, curriculums, jobs, training sessions.
- [TalentCards API](https://github.com/epignosis/talentcards-api-wrapper): REST API with a first-party PHP wrapper.
